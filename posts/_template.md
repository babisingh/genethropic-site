## A sub-heading

- Bullet points start with a dash.
- **Bold** and *italic* work, and so do [links](https://example.org).

Put pictures in the `posts/images` folder and show them like this:

![What the picture shows](images/my-figure.png)

*Figure 1. A line in italics right under a picture becomes its caption.*

The `label` line is a small tag such as "negative result", "in progress" or
"side quest". The `image` line is the picture shown when the entry is shared.
Both can be left out.

To post a Claude artifact instead of written text, save the artifact as an
HTML file and put it in this folder with a dated name, for example
`2026-12-01-codon-usage-explorer.html`. Its page title becomes the headline.

Files whose name starts with an underscore, like this one, are never published.
